# 要因カレンダー（events.csv）

混雑に影響しそうな「日付が決まっている出来事」を1行ずつ書きます。
毎日の学習のときに、ここに書いた日の混雑が普段の予想とどれくらい違ったかを自動で検証し、
効果がはっきりした要因だけを予想に使います。**未来の日付を書けば、その日の予想にも反映されます。**

| 列 | 内容 |
| --- | --- |
| start, end | 期間（YYYY-MM-DD）。1日だけなら同じ日付 |
| park | `tdl`（ランド）・`tds`（シー）・`both` |
| type | 下の表のどれか |
| name | 出来事の名前 |
| source | 情報源のURL（公式サイト・ブログ・Xの投稿など） |
| note | メモ（任意） |

| type | 意味 | 予想に使うタグ |
| --- | --- | --- |
| `merch` | グッズ発売日 | その日・1〜3日後・4〜7日後・発売後最初の土日（それぞれ別の要因として検証） |
| `restock` | 人気グッズの再入荷・再販 | その日（期間でも可） |
| `soldout` | 人気グッズが売り切れている期間 | start〜end の毎日 |
| `open` | アトラクション・エリアのオープン | 開始日から1週間 |
| `show` | 新パレード・ショーの開始 | 開始日から3日間 |
| `event` | パークのイベント期間 | 前日（スニーク）・開始から1週間・最終週 |
| `short` | 時短営業・貸切（その日の閉園が早い） | その日（もう片方のパークにも「相手が時短」タグ） |

過去のイベント期間と時短営業は、Queue-Times の記録（`data/history/*.csv`）からも自動で作られます。
iPhone からは GitHub のサイトでこのファイルを開き、鉛筆マークから編集できます。
